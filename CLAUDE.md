# Стрелец и нечисть — заметки для Claude

Пиксельная игра-тренажёр по уравнениям, славянский мрачный фолк. Играется на GitHub Pages: https://zpl3s.github.io/equation-dungeon/ (репозиторий zpl3s/equation-dungeon, ветка main; push в main = деплой).

## Как работать с пользователем
- Общение по-русски, коротко. Пользователь бережёт токены.
- Перед новой крупной фичей — бриф через виджет-анкету (elicitation), он выбирает ответы кликами. Потом строим за один заход.
- Работаем итерациями, после каждой пользователь смотрит результат:
  1. **Кремль** (в работе) → 2. **Герои** (стрелец, Кот Учёный) → 3. **Одна зона нечисти: Поле** → дальше зоны и окружение леса по одной.

## Устройство
- `index.html`, `css/style.css`; `js/math.js` — генераторы уравнений с пошаговыми решениями; `js/world.js` — зоны, нечисть, уроки, здания `BLD`, профили движения; `js/sprites.js` — общий рендер спрайтов и процедурная анимация (игра и мастерская); `js/map.js` — изометрическая карта (сетка 49×49, тайл 40×20) и фоны боя; `js/game.js` — состояние, экраны, бой; `js/art.js` — промпты PixelLab.
- `studio.html` — мастерская спрайтов: карточки существ, промпты, загрузка, выбор основы из вариантов, отражение, превью с анимацией.
- `assets/env/atlas.*` — атлас окружения из CC0-паков (`tools/build_assets.py`, исходники паков не в репо).
- `assets/sprites/<id>.png` — спрайты (64×64, боссы тоже 64 — в игре ×3); `<id>_idle|_attack|_spawn.png` — анимации лентой.
- `assets/candidates/<id>/` — варианты из PixelLab для выбора (в .gitignore).

## Правила арта (PixelLab, Tier 1: 2000 генераций/мес)
- Нечисть смотрит ВЛЕВО (на стрельца), стрелец — вправо. Проверять до сохранения.
- Основу НЕ выбирать самому: все варианты класть в `assets/candidates/<id>/`, пользователь выбирает в studio.html.
- Pro: число вариантов зависит от холста, цена 10 ген: ≤64px → 16 вариантов (самое выгодное), 86–128 → 4, 171–256 → 1. Здания — «всё в Pro». Стилевой образец — уже одобренные спрайты; палитра — `assets/palette.png`.
- Рисованные анимации только «покой», «атака», «появление»; попадание и гибель — процедурные.
- Сообщать пользователю, сколько генераций потрачено.

## Проверка
- `python3 -m http.server` не может читать ~/Documents (приватность macOS): копировать проект rsync'ом в scratchpad и запускать превью оттуда.
- В скрытой панели браузера requestAnimationFrame не тикает — в тестах вызывать `animLoop(performance.now())` вручную.
- Коммиты с подписью `Co-Authored-By: Claude …`, сразу push.
