# Спрайты нечисти

Все промпты, настройки PixelLab и загрузка картинок собраны в **мастерской**: открой `studio.html` из папки проекта (лучше в Chrome).

- Промпты лежат в `js/art.js`: общий стиль `ART_STYLE`, негативный промпт `ART_NEG` и описание каждого существа.
- Мастерская сама сохраняет PNG в `assets/sprites/<id>.png`. Если браузер не умеет писать в папку, файл скачается с правильным именем.
- Палитра для Target Palette в PixelLab: `assets/palette.png`.
