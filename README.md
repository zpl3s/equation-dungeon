# Данжон уравнений

Пиксельная игра-тренажёр: спускаешься в данжон и побеждаешь монстров, решая уравнения. Урон зависит от сложности уравнения и от того, насколько быстро ты его решил.

**Играть:** https://zpl3s.github.io/equation-dungeon/

## Как устроено
- Одна тема = один монстр: Слизень (простые линейные) → Гоблин → Скелет → Голем (скобки) → Призрак (дроби) → Бес (неравенства) → Орк (квадратные) → Мимик (модули) → Близнецы (системы) → Змей (квадратные+).
- Забег на 15–20 минут: 3 этажа, привал с лавкой между ними, в конце босс Лорд Икс.
- Крит ×2, если уложился в половину нормы времени. Комбо за серию верных ответов.
- Новая тема открывается после 8 верных ответов и 70% точности по текущей. Слабые темы попадаются чаще.
- Прогресс хранится в браузере (localStorage).

## Локально
Открой `index.html` в браузере — сборка и установка не нужны.
