Мастерская спрайтов

Здесь собрана вся нечисть, которую нужно нарисовать. У каждого существа есть готовые промпты для PixelLab: для самого спрайта, для анимации покоя и для атаки. Загруженные картинки сразу сохраняются в игру. Открывай эту страницу двойным кликом по studio.html в папке проекта, лучше в Chrome.

Как генерировать в PixelLab

  1. Спрайт. Открой pixellab.ai → Create, инструмент Create image, режим Pro. Он выдаёт пачку вариантов: на холсте 64×64 — 16 штук, на 96×96 — 4. Пачка стоит 10 генераций. Скачай лист целиком и перетащи на строку «Спрайт»: мастерская покажет сетку, кликни нужный вариант.
    Размер холста64×64, у хозяев зон (★) — 96×96 Descriptionкнопка «Копировать» у строки «Спрайт» No backgroundвключить Style imageпервый удачный спрайт — для всех остальных, тогда стиль будет один Color palettepalette.png — 32 цвета нашего леса Reference imagesпо желанию, до 4 картинок с видом существа (подсказки есть в некоторых карточках)
    Дешёвый вариант — режим PixFlux: 1 генерация = 1 картинка. Camera view — side, Direction — как в карточке, Transparent background — включить, Negative description — .
  2. Анимации — по желанию. Игра сама оживляет любой спрайт: дыхание, парение, замах, вспышку, рассыпание. Как это будет выглядеть, видно прямо в карточке, а кнопки под превью проигрывают атаку, попадание и гибель. Настоящие покадровые анимации в PixelLab (Animate → Animate with text) доступны только по платной подписке. Если появятся, грузи их в строки «Покой» и «Атака» (PNG-лист, GIF или все кадры разом), и игра возьмёт их вместо кодовых.
  3. Открой игру (index.html): спрайты и анимации уже там. Загрузишь несколько — скажи мне, я выложу их на сайт.
