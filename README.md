# Стрелец и нечисть (рабочее название)

Пиксельная игра-тренажёр по уравнениям в сеттинге славянской мифологии. Царь шлёт стрельца «туда — не знаю куда», а за стенами кремля — лес, полный нечисти. В цель идёт только выстрел, наведённый точным счётом.

**Играть:** https://zpl3s.github.io/equation-dungeon/

## Как устроено
- **Кремль** в центре изометрической карты: кузница, изба знахарки, торг, изба-читальня с Котом Учёным (уроки, бестиарий, летопись). Остальные здания пока заглушки.
- **8 зон леса** вокруг, у каждой свои уравнения, своя нечисть и свой хозяин:
  Поле (простые) → Берёзовая опушка (в два шага) → Река и омут (иксы с обеих сторон) → Еловая чаща (скобки, дроби) → Старая дубрава (неравенства) → Курганы (квадратные, модули) → Горы и пещеры (системы) → Кощеево царство (всё вперемешку).
- **Поход** занимает 15–20 минут: 4 поляны, привал, в конце хозяин зоны. Хозяин выходит, только когда темы зоны освоены (8 верных и 70% точности). Победил его — открылась следующая зона.
- **Уроки:** перед новой темой Кот Учёный объясняет правило, разбирает пример по шагам и даёт 3 тренировочных уравнения без урона. После ошибки в бою можно открыть пошаговое решение.
- Крит ×2 за скорость, комбо, повторение старых тем, бестиарий с преданиями. Прогресс хранится в браузере.

## Своя нечисть
Открой `studio.html` — это мастерская: список всей нечисти, промпты и настройки для PixelLab, загрузка PNG прямо в `assets/sprites/`. У каждого существа слоты: спрайт `<id>.png`, анимации покоя `<id>_idle.png`, атаки `<id>_attack.png` и появления `<id>_spawn.png` (кадры в ряд). Варианты, которые генерирует Claude, кладутся в `assets/candidates/<id>/` (в git не попадают) и выбираются в мастерской кликом. Игра подхватывает всё сама.

## Структура
- `index.html`, `css/style.css`
- `js/math.js` — генераторы уравнений, шаги решений, проверка ответа
- `js/world.js` — зоны, нечисть, уроки, здания, временные спрайты
- `js/sprites.js` — общий рендер спрайтов и процедурная анимация (игра и мастерская)
- `js/map.js` — изометрическая карта и фоны боя
- `js/game.js` — состояние, экраны, бой
- `assets/env/` — атлас окружения, собран скриптом `tools/build_assets.py`
