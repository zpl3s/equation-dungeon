# Конституция проекта «Стрелец и нечисть»

Главный документ проекта: зачем он, как устроен, куда идём и где мы сейчас. Любая новая сессия Claude (в том числе с другого аккаунта) читает его первым. Обновлять после каждой итерации: разделы «Где мы сейчас» и «Журнал решений».

Играть: https://zpl3s.github.io/equation-dungeon/ · репозиторий: https://github.com/zpl3s/equation-dungeon (ветка `main`, push = деплой на GitHub Pages) · локально: `~/Documents/equation-dungeon`.

## 1. Зачем
- Пользователь тренируется решать уравнения по 15–30 минут в день, на бумаге, от простых линейных до систем, неравенств и модулей.
- Обёртка — пиксельная RPG: решённое уравнение — это выстрел, скорость и сложность дают урон.
- Таймера-давления нет: скорость влияет только на урон.

## 2. Как работать с пользователем
- Общение по-русски, коротко, без воды. Пользователь бережёт токены и генерации PixelLab.
- Перед крупной фичей — бриф через виджет-анкету (elicitation): вопросы с кликабельными ответами, первый вариант — рекомендация. Потом строим за один заход.
- Итерационно: одна итерация → пользователь смотрит → следующая. Не забегать вперёд.
- Решения пользователя не пересматривать без его просьбы. Если сомневаешься, спроси через анкету.
- После работы проверять в браузере, коммитить и пушить, коротко отчитываться: что сделано, что проверено, что нет.

## 3. Сеттинг и сюжет
- Мрачный славянский фолк-хоррор. Кремль уютный, лес жуткий.
- Герой — стрелец (по мотивам «Про Федота-стрельца»). Царь шлёт его «туда — не знаю куда», а в лесу он постоянно нарывается на нечисть. Нечисть берёт только выстрел, наведённый точным счётом.
- Наставник — Кот Учёный (Лукоморье), живёт в избе-читальне, ведёт уроки.
- Название игры не выбрано («потом придумаем»), рабочее — «Стрелец и нечисть».

## 4. Игровой дизайн (как есть сейчас)
**Темы уравнений** (`js/math.js`, у каждой генератор с пошаговым решением): простые линейные → в два шага → иксы с обеих сторон → скобки → дроби → неравенства → квадратные → модули → системы → квадратные+. Ответы проверяются гибко (дроби, `x=`, запятые, `<=`).

**Мир** — изометрическая карта: кремль в центре, вокруг 8 зон по кругу. Каждая зона — свои темы, нечисть и хозяин.

| Зона | Темы | Нечисть | Хозяин |
|---|---|---|---|
| Поле с полуденницами | простые линейные | Полевик, Анчутка, Межевик | Полуденница |
| Берёзовая опушка | в два шага | Аука, Мавка, Лесавка | Кикимора |
| Река и омут | иксы с обеих сторон | Русалка, Утопленник, Шишига | Водяной |
| Еловая чаща | скобки, дроби | Волколак, Чёрт, Блуд | Леший |
| Старая дубрава | неравенства | Лихо Одноглазое, Див, Соловей-Разбойник | Баба Яга |
| Курганы | квадратные, модули | Упырь, Навь, Игоша | Вий |
| Горы и пещеры | системы | Полоз, Огненный змей, Чудь белоглазая | Змей Горыныч |
| Кощеево царство | квадратные+ и всё вперемешку | Костяной ратник, Мара, Морок | Кощей Бессмертный |

**Поход** (~15–20 минут): 4 поляны (1–2 монстра), привал (+25% HP), в конце хозяин. Хозяин выходит, только когда темы зоны освоены: 8 верных и 70% точности по последним 10. Иначе вместо него выходит вожак. Победа над хозяином открывает следующую зону. В бою 25% задач — повторение старых тем (в Кощеевом царстве 50%), слабые темы попадаются чаще.

**Бой**: урон = 10 × сложность × скорость × комбо × бонусы. Уложился в половину нормы времени — крит ×2. Ошибка: нечисть бьёт, комбо сгорает, можно открыть пошаговое решение.

**Уроки**: перед новой темой — правило, пример по шагам, 3 тренировки без урона. Перечитать можно в избе-читальне.

**Прогресс**: опыт и уровни дают HP и урон; золото тратится в кузнице (урон, броня), у знахарки (зелья) и на торге (свитки-подсказки). Ещё есть серия дней, летопись (статистика) и бестиарий с преданиями. Сохранение — `localStorage`, ключ `eqdungeon.v1`.

**Кремль** (здания в `js/world.js`, список `BLD`): царские палаты (царские поручения — в работе), церковь (функция «решу позже»), изба-читальня, кузница, изба знахарки, торг, капище, баня, корчма. У последних трёх функций пока нет.

## 5. Арт
- **PixelLab**, тариф Tier 1: $12 в месяц, 2000 генераций. Подключён к Claude Code через MCP (`pixellab`, user scope). Сообщать пользователю, сколько генераций потрачено.
- **Правила:**
  - Нечисть смотрит ВЛЕВО (на стрельца), стрелец — вправо. Проверять до сохранения.
  - Основу НЕ выбирать самому. Все варианты класть в `assets/candidates/<id>/` (в .gitignore), пользователь выбирает в `studio.html`.
  - Pro: цена 10 генераций, число вариантов зависит от холста: ≤64px → 16 вариантов (самое выгодное), 86–128 → 4, 171–256 → 1. Существа и хозяева — на холсте 64 (в игре хозяин ×3). Здания — «всё в Pro».
  - Стиль: мрачный фолк, приглушённые земляные тона, тёмный контур. Стилевой образец — одобренные спрайты (первый — `assets/sprites/poludnitsa.png`), палитра — `assets/palette.png`.
  - Рисованные анимации только «покой», «атака», «появление». Попадание и гибель — процедурные. Без рисованных анимаций игра оживляет спрайт сама (`js/sprites.js`): дыхание, парение, замах, вспышка, рассыпание, появление.
- **Мастерская** `studio.html` (открывать из папки проекта в Chrome, подключить папку `equation-dungeon`): вкладки существ и кремля, промпты, выбор основы из вариантов, «Отразить», превью с анимацией, загрузка своих PNG и анимаций.
- **Файлы**: `assets/sprites/<id>.png`, `<id>_idle|_attack|_spawn.png` (кадры в ряд); здания — `assets/buildings/<id>.png`; окружение пока из CC0-атласа `assets/env/` (`tools/build_assets.py`). Лес перерисовываем в PixelLab по зоне за раз.

## 6. Техника
- Чистый HTML/JS без сборки: `index.html`, `css/style.css`, `js/{math,world,sprites,map,game,art}.js`, `studio.html`.
- Проверка: `python3 -m http.server` не читает `~/Documents` (приватность macOS), поэтому копировать проект rsync'ом в scratchpad и открывать превью оттуда. В скрытой панели браузера `requestAnimationFrame` не тикает — в тестах вызывать `animLoop(performance.now())` вручную.
- Коммиты на русском, с подписью Claude, сразу push в `main`. Если в папке параллельно работает другая сессия, добавлять в коммит только свои файлы.

## 10. Переезд и настройка с нуля
На том же Mac под другим аккаунтом Claude проект, история git, настройки MCP (`~/.claude.json`) и PixelLab остаются на месте. Достаточно войти в новый аккаунт и открыть папку `~/Documents/equation-dungeon`. Проверить PixelLab: `claude mcp list` должен показать `pixellab ✔ Connected`.

На другом компьютере:
1. `git clone https://github.com/zpl3s/equation-dungeon.git` и `gh auth login` (аккаунт GitHub `zpl3s`).
2. Поставить Claude Code: `curl -fsSL https://claude.ai/install.sh | bash`.
3. Подключить PixelLab, вставив токен со страницы Account на pixellab.ai: `claude mcp add pixellab https://api.pixellab.ai/mcp -t http -s user -H "Authorization: Bearer ТОКЕН"`. Новая сессия увидит инструменты.
4. Файлы `assets/candidates/` в git не хранятся. Если итерация не закончена, их нужно перенести вручную или сгенерировать заново.

Стартовая фраза для новой сессии: «Прочитай docs/PROJECT.md и CLAUDE.md и продолжи с раздела „Где мы сейчас“».
